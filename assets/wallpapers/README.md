# Wallpapers / 壁纸资源

Store optional, non-sensitive, appropriately licensed wallpaper images here.

- Images are **not required** to use the current themes.
- This repository is public: do not commit private photos, credentials, or sensitive artwork.
- To reference an uploaded image in CSS, use its direct GitHub Raw URL.
- Prefer compressed WebP/JPG/PNG images with reasonable dimensions and file sizes.

此处用于存放可公开使用的壁纸。上传后可通过 GitHub Raw 图片链接应用到 CSS 中。请勿提交私人或敏感图片。
