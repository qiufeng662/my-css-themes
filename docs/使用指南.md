# Edge + Stylus 使用指南

[English README](../README.md) | [中文 README](../README.zh-CN.md)

## 第一步：关闭可能导致卡顿的旧 CSS

1. 在 Edge 中打开 [ChatGPT](https://chatgpt.com)。
2. 点击右上角的 **扩展（拼图）** 图标，找到并打开 **Stylus**（可先固定到工具栏）。
3. 在「此网站的样式」列表里，将旧版 **ChatGPT Dreamy Glass / 紫色 4 号** 的开关关闭。
4. 其他 ChatGPT 主题也先关闭；建议把 ChatGPT 官方的外观设置为「浅色」。
5. 按 **Ctrl + R** 刷新，先确认页面没有其他问题。

## 第二步：直接安装新主题（不需要自己改代码）

下面五款都是相互独立的 **Lite 轻量版**：

| 主题 | 点击直接安装 |
| --- | --- |
| 紫色渐变（无壁纸） | [Dreamy Gradient Lite](https://raw.githubusercontent.com/qiufeng662/my-css-themes/main/themes/chatgpt/dreamy-glass.user.css) |
| 粉彩壁纸 | [Pastel Gradient](https://raw.githubusercontent.com/qiufeng662/my-css-themes/main/themes/chatgpt/wallpaper-pastel.user.css) |
| 月夜星空壁纸 | [Anime Night Sky](https://raw.githubusercontent.com/qiufeng662/my-css-themes/main/themes/chatgpt/wallpaper-anime.user.css) |
| 晨雾森林壁纸 | [Misty Forest](https://raw.githubusercontent.com/qiufeng662/my-css-themes/main/themes/chatgpt/wallpaper-forest.user.css) |
| 紫蓝星云壁纸 | [Cosmic Nebula](https://raw.githubusercontent.com/qiufeng662/my-css-themes/main/themes/chatgpt/wallpaper-nebula.user.css) |

1. **确保 Edge 已安装 Stylus**（[官方扩展项目](https://github.com/openstyles/stylus)）。
2. 点击任一主题上方的链接（必须打开 `.user.css` **原始文件**页面）。
3. Stylus 一般会自动打开「Install style / 安装样式」窗口。点击安装。
4. 回到 ChatGPT 页面，刷新即可。
5. 如果只是显示 CSS 文本而未打开安装页面，打开 Stylus 的设置并检查是否启用识别 .user.css 安装页面；也可从 Stylus 管理页选择「新建 UserCSS」后粘贴完整代码。

## 第三步：切换四张图片

你可以将四款壁纸主题都安装到 Stylus；**切换时不必重新下载或改图片链接**。

1. 打开 ChatGPT。
2. 点击右上角 Stylus 图标。
3. 先将当前正在使用的 ChatGPT 主题**关闭**。
4. 将你想换成的另一套主题**打开**。
5. 刷新一次 ChatGPT。

**注意：同一个网站仅启用一套完整主题。** 切换是浏览器本地行为，不需要去 GitHub 修改文件。

## 为什么旧版可能很卡？

旧版紫色主题使用了大面积 `backdrop-filter` 实时模糊、`:has()` 匹配以及对所有按钮添加动画等写法，可能触发较多样式计算和绘制工作。Lite 版移除了这些特效和过宽选择器，并使用较小的 WebP 壁纸（58–379 KB）。

这是一项基于 CSS 的针对性优化，并非已在你的 Edge 上实测的性能保证。若新版仍卡顿，请关闭 Stylus 所有 ChatGPT 样式、刷新浏览器做对照，并把页面截图或浏览器表现告诉我。

## 以后增加其他网站

在 `themes/网站域名/` 建独立 CSS 文件。不同网站需要各自适配，不能直接把 ChatGPT 的 CSS 套到任何网站。
