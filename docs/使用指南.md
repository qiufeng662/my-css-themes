# Edge + Stylus 使用指南

## 一、安装扩展

在 Microsoft Edge 中安装 [Stylus](https://github.com/openstyles/stylus) 浏览器扩展。

## 二、安装单个网站的主题

1. 在 `themes/` 下选择目标网站及其 CSS 文件。
2. 复制整个 `.user.css` 文件的内容。
3. 打开 Stylus 扩展，选择编写新样式（或 UserCSS 编辑模式）。
4. 粘贴完整内容，保存。
5. 打开目标网站并刷新，查看主题是否生效。

**域名必须匹配**：例如 `domain("chatgpt.com")` 只影响该网站及其子域名，不会影响 GitHub。无需给所有网页启用同一段 ChatGPT 专用 CSS。

## 三、切换和关闭

在 Stylus 管理页面中可逐一启用、禁用、编辑、删除主题。
同一站点的两款完整主题不要同时启用，以免产生 CSS 层叠冲突。

## 四、创建新主题

1. 复制 `templates/site-theme.user.css`。
2. 将文件放入 `themes/目标站点/`。
3. 修改 `@name`、`@namespace`、`@version` 和 `@-moz-document domain("example.com")`。
4. 编辑颜色变量和少量稳妥的选择器。
5. 在 Edge 中验证阅读、按钮、输入框、弹窗、深色模式。
6. 上传到 GitHub。

## 五、关于“所有网页”

**两种主题作用域不同：**

- 站点专用主题：精细定制单个网站。适合 ChatGPT、GitHub、论坛、阅读网站等。
- 通用主题：希望在多数网页上都应用的颜色/字体调整。由于各站结构不同，通常不能保证一致外观；强行覆盖所有背景、按钮或表单可能破坏阅读与交互。

因此本仓库推荐**站点专用优先、通用样式谨慎开发**。通用主题未来放在 `themes/universal/`，目前仅预留目录，尚无已验证的通用样式。

## 六、常见问题

- **不生效**：确认 Stylus 已启用、样式没有被禁用、网页域名匹配，并刷新网页。
- **显示异常**：暂时禁用主题验证是否为 CSS 冲突，再缩小选择器覆盖范围。
- **字体颜色难看清**：检查明暗模式冲突、`color` 与 `background` 搭配。
- **更新了 GitHub 却未变化**：GitHub 上的提交不等于浏览器内的自动更新，需要在 Stylus 中同步或重新安装新版本。
